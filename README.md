# 吾今有世家存档编辑器

第三方独立本地存档处理工具，仅修改本地 GameData.es3 存档文件。

一个纯图形界面的**《吾今有世家》**存档编辑器。双击打开窗口，点几下鼠标就能改存档 ——
不用记参数、不用敲命令、不用背菜单号。

## 一、特性

- **纯图形界面**：六个页签，所有操作都是按钮和勾选框，改之前先把完整改动清单摆出来给你看
- **改前预览**：每一次修改都先 dry-run 列出「哪个字段、从什么、改成什么」，你点「是」才真正落盘
- **自动备份**：每次写盘前自动备份，最多保留 10 份，旧备份自动清理
- **原子写入**：先写临时文件再整体替换，游戏读到的永远是完整文件，不会出现半个存档
- **一条条撤销**：改错了可以一层层往回退，不用去翻备份文件夹
- **天赋 / 专精 / 熟练度**：每个人的天赋类型、天赋潜力、专精技能、熟练度都能单独调
- **生成神级门客**：一次生成一批门客，属性和专精自动铺满全部类型
- **勾选式加物品**：仓库物品全部列成勾选框，能搜索、能全选/反选，**不用再记物品编号**
- **库房容量 / 数量归位**：解决「东西买不进去 / 存不进去」的爆仓问题 —— 先抬府邸的库房容量，抬不动就用数量归位把每种物品压回合理值
- **家族全员一键修改**：一个按钮作用到**全体族人（含幼年成员）** —— 年龄统一 20 岁、四项属性与
  潜力拉满、技能随机重新分配
- **存档格式零改动**：序列化结果与游戏原文件逐字节一致，不引入任何格式漂移

### 3. 六个页签分别做什么

#### 常用

- **★ 一键全改** —— 一次做完这几件事：铜钱元宝拉满 → 全员属性拉满 → 全员长寿健康易孕 → 清除全员负面状态 → 提高库房容量
- **铜钱元宝拉满** —— 只改钱
- **↩ 撤销上一次改动** —— 把上一次写盘整个回滚

> 「一键全改」**不会**改动成员年龄。要统一年龄请用「人物与技能」页的
> **★ 家族全员一键修改**，那是单独一个按钮。

#### 门客

- **★ 生成** —— 生成神级门客，可以指定人数与名字来源（历史谋士名字池 / 自己填）
- 生成出来的门客**默认就是满熟练度**，天赋在四种之间、专精在六种之间自动轮着铺开，
  保证一次生成的一批人刚好覆盖全部天赋类型和全部专精技能

#### 人物与技能

先把成员列成表（门客 / 族人可筛选），勾选要改的人，然后：

- **天赋类型**：无 / 文学 / 武学 / 商业 / 艺术
- **天赋潜力**：0 ~ 100
- **专精技能**：无 / 巫 / 医 / 相 / 卜 / 媚 / 工
- **熟练度**：0 ~ 100

底部有 **应用到全部门客** / **应用到全部族人** 和 **★ 全部拉满**。

还有 **★ 家族全员一键修改（含幼年成员）**，一次作用到全部族人：

- **年龄**统一改成 20 岁（**幼年成员也会一起改**，这是需求里明确要的）
- **文 / 武 / 商 / 艺、心情、声誉、魅力、健康、计谋** 九项全部拉满
- **天赋潜力**拉满
- **技能在六种专精之间随机重新分配**，每个人拿到的都不一样
- **天赋类型默认不动**（保持原有天赋），想连天赋一起随机就别用这个按钮

> **关于熟练度**：族人的「熟练度」格位本工具**没有核对过**，所以默认不写它，
> 免得把没验证过的字段写坏。界面上有「连族人熟练度也写」的勾选框，
> 你确认过想写再勾。门客的熟练度是核对过的，正常写。

> **重要**：专精技能和熟练度是**两个独立字段，必须一起写**。
> 只写专精，游戏面板上会显示出技能名字，但那个技能不生效；
> 只写熟练度，面板上看不出变化。两个都写了，功能和显示才对得上。

#### 仓库与势力

- **往仓库加物品（勾选式）** —— 285 种物品全部列成勾选框，直接勾你要的，
  **不需要再去查物品编号**：
  - 上面有搜索框，打「酒」「盐」这种名字就行，不用记数字
  - **筛选** / **全选** / **全不选** / **反选** 四个按钮；勾选只作用于**当前筛出来的那批**
  - **只显示仓库已有的** —— 想给现有物品加量时，先勾这个，列表就只剩你仓库里有的东西
  - 右下角写着「已勾选 N 种」，不用一个个数
  - 选好数量（默认 9999999）和方式（**增加** / **覆盖**），点 **★ 加入仓库**
- **★ 库房容量（爆仓：东西买不进去 / 存不进去）** —— 直接改存档里府邸的库房容量。
  界面上会显示「库房容量」和「仓库物品总数量」，两者一比就知道是不是爆仓了。
  **只增不减**：填的值比现值小就一个字都不改，避免手滑把容量调低。
- **★ 数量归位** —— 把仓库里每种物品的数量统一改成指定值（默认 999）。
  ⚠ 这个操作会**减少**数据：任何比目标值多的物品都会被砍到目标值。
  改动清单会在写盘前逐条列出来，看一眼再确认。它是容量实在抬不动时的真正解法。
- **★ 全部拉满** —— 仓库里已有的每种物品直接拉到上限，只增不减
- **设置** —— 驻军兵力 / 士气
- 城防、世家好感度、奴隶数量、物价等也在这里

> **爆仓卡在哪儿**：容量挂在**府邸**的库房上，而且比的是**物品数量**而不是物品种类数。
> 这两条是游戏自己的文案写明的 ——「（物品数量：@，库房容量：$）」，
> 「库房容量已满，请在**府邸**建造或升级库房！」，
> 「（库房容量不足,无法交易）」「(库房容量已满，无法购买)」。
>
> 所以本工具改的是府邸数据的第 3 项（真实存档里是 `410`），第 5 项是它的副本、一起抬。
> ⚠ 但**容量是有限的**：一仓库几百种物品、每种上千万件时，把容量抬到几十亿也未必够。
> **真正管用的做法是「数量归位」** —— 把每种物品压回合理数量，爆仓立刻解除。
>
> 改完进游戏看一眼仓库面板的「库房容量」是否变大；没变就用 **↩ 撤销上一次改动** 退回来。
> 这两个操作都只影响仓库相关数据，不动钱、不动人。

#### 工具

- **查看存档结构（顶层字段）** —— 列出存档里所有顶层字段名
- **查看都有哪些文件** —— 列出存档文件夹里的全部文件
- **打开存档文件夹** —— 直接在资源管理器里打开
- **改它** —— 手动指定字段路径和值，改那些界面上没做按钮的东西
- **只备份，什么都不改** —— 动手之前先留个底

#### 改动日志

每一次修改的完整清单都在这里，包括每个字段的旧值和新值。
出问题的时候把这块内容发出来，比描述「我点了什么」有用得多。

## 四、安全机制

这个工具在「别把你的存档弄坏」上做了几层防护：

1. **改前预览**：先列出完整改动清单，确认了才写
2. **自动备份**：写盘前备份为 `GameData.es3.bak-日期时间`，自动保留最近 10 份
3. **原子写入**：先写 `.tmp` 再 `os.replace()` 整体替换，不会出现写了一半的文件
4. **写后复校**：写完立刻重新读一遍并解析，确认还是合法 JSON 才认为成功
5. **格式保真**：单行紧凑格式、无 BOM、中文原样、`:` 和 `,` 后不加空格 ——
   序列化结果与游戏原文件**逐字节一致**
6. **类型安全**：绝不把数字写进字符串槽位，绝不碰 `__type` 字段
7. **零输入容错**：界面上什么都不填时明确报「没东西可改」，而不是瞎写一个值进去

**仍然强烈建议你手动备份一次存档再动手。**

## 七、常见问题

**Q：改了之后进游戏没变化？**
游戏只在**载入存档时**读 `GameData.es3`，回到标题界面时会把内存里的数据写回文件。
所以正确顺序是：**先进游戏确认位置 → 退出到标题界面（或完全退出）→ 这时再改 → 再载入存档**。
在游戏运行中改文件，会被游戏退出时写回的数据覆盖掉。

**Q：改完存档载入不了？**
把 `GameData.es3.bak-日期时间` 改回 `GameData.es3` 就能还原。
或者用界面上的「撤销上一次改动」。

**Q：自动检测找不到我的存档？**
存档可能不在默认位置。用「浏览…」手动选到含 `GameData.es3` 的那个文件夹。
注意要选**文件夹**，不是选文件。

**Q：程序打开时提示「找不到预设」？**
`presets.json` 必须和主程序放在同一目录。打包成 exe 时它已经被打进去了；
如果你是直接跑源码，检查一下文件是不是被移动过。

**Q：专精技能我改了但没效果？**
见「人物与技能」那一节的提示 —— 专精和熟练度必须**两个一起写**。

**Q：东西买不进去，说「库房容量已满」？**
用「仓库与势力」页的 **★ 库房容量**。界面上会先把「库房容量」和「仓库物品总数量」
显示出来 —— 游戏比的是**数量**，总数量大于容量就是爆仓。先试着把容量填大点。
如果填到很大仍然提示已满（每种物品上千万件时很正常），就用同一张卡片上的
**★ 数量归位**，把每种物品压回 999 之类的合理值，爆仓立刻解除。
两个操作都能用「↩ 撤销上一次改动」退回来。

**Q：家族全员一键修改会不会把小孩也改了？**
**会，而且是故意的。** 需求就是「作用于全部家族成员（含幼年成员）」，
所以两三岁的幼年成员也会被一起改成 20 岁。改之前预览清单里会逐条列出来，
不满意就别点确认。
